# Reference Documents

Full source documents go here (PDFs, or better, their text converted to
Markdown). Agents should **not** read this folder at the start of a task. Open a
document only to look up the exact wording behind a specific rule ID.

Suggested contents:

- `NIST.SP.800-63B-4.pdf` — authentication and passwords
- `NIST.SP.800-53r5.pdf` — security and privacy controls (large: ~490 pages)
- `NIST.SP.800-218.pdf` — Secure Software Development Framework
- `NIST.SP.800-218A.pdf` — SSDF profile for generative AI and foundation models
- `OWASP-ASVS-5.0.md` — Application Security Verification Standard
- `OWASP-Top-10-2025.md` — summary of each category

Download them yourself from nist.gov and owasp.org so you know the copy is
authentic. Converting a PDF to Markdown first makes it far easier for an agent
to search when it does need to look something up.
